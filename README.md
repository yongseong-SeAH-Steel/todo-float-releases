# TODO 플로트

윈도우 화면 오른쪽에 항상 떠 있는 작은 개인 업무 목록입니다. Google 캘린더·Gmail과 연결해 오늘 일정과 업무 후보를 함께 볼 수 있습니다.

## 받기

**[최신 버전 받기 →](https://github.com/yongseong-SeAH-Steel/todo-float-releases/releases/latest)** 에서 `TODO-Float-Portable.zip`을 받습니다.

1. zip을 계속 둘 폴더에 압축 해제합니다. (예: `문서\TODO Float`. 다운로드 폴더는 정리하다 지우기 쉬워 권하지 않습니다)
2. `TODO.exe`를 더블클릭합니다.
3. 처음 실행하면 Windows 로그인 때 자동으로 열리도록 등록됩니다.

설치·실행 중 Windows 또는 회사 백신의 보안 안내가 나올 수 있습니다. 공식 다운로드 파일인지 확인하고 회사 보안 정책에 따라 처리하세요.

## 이미 설치한 분 — ZIP을 다시 받을 필요 없습니다

앱을 완전히 종료했다가 실행하거나 PC를 재부팅하면 새 버전을 확인합니다. 새 버전이 있으면 **변경 내용과 업데이트 여부를 묻는 창**이 뜹니다(2.2.2부터).

- **예**: 업데이트를 설치하고 앱을 다시 시작합니다. 업무·설정·Google 연결은 유지됩니다.
- **아니요**: 기존 버전으로 계속 사용하고, 다음 실행 때 다시 안내합니다.
- 이미 최신 버전이면 업데이트 안내는 뜨지 않습니다.
- 트레이 아이콘 오른쪽 클릭 → **업데이트 확인**으로 직접 확인할 수도 있습니다.

창의 **×는 트레이로 숨기기**입니다. 완전히 종료하려면 트레이 아이콘 오른쪽 클릭 → **종료**를 선택하세요.

아주 오래된 Google Drive 배포본처럼 앱 내 업데이트가 없는 버전만 최신 ZIP을 한 번 받아 실행하세요. 실행 중인 이전 앱을 닫을지 물으면 **예**를 선택합니다. 기존 업무·설정은 이어지고, 바로가기는 새 위치로 갱신됩니다.

백신의 실행 허용 안내는 TODO 업데이트 안내와 별개입니다. AhnLab V3의 ‘다음부터 묻지 않음’은 백신 실행 확인에만 적용되며 앱의 업데이트 안내를 끄지 않습니다. 회사 보안 정책에 따라 처리하세요.

## 주요 기능

- **업무 목록** — 상태(진행 전·진행 중·대기), 우선 업무, 요일 반복, 드래그로 순서 변경, 검색, 완료 이력 CSV
- **마감일과 알림** — 지연·오늘·내일 마감을 색으로 표시, 시간을 정하면 10분 전 알림, 아침에 오늘 마감 요약, 마감일순 보기
- **빠른 추가** — 어디서든 `Ctrl+Alt+T`. `견적 회신 내일 15:00`처럼 쓰면 마감까지, 앞에 `!`를 붙이면 우선 업무
- **보고서/내보내기** — 주간 보고 초안(이번 주·지난 주의 완료·진행 중·예정)을 복사하거나 완료 목록을 CSV로 저장. 좁은 창에서는 `보고서`로 표시
- **화면 설정** — LIGHT MODE / DARK MODE, 투명도 조절. 하단은 이용자 수(관리자 계정에만 표시) → 투명도 → 모드 → 보고서/내보내기 순서
- **Google 캘린더** — 진행 탭 위에 오늘 일정, 업무 수정 창에서 바로 일정 만들기
- **제안함** — 업무 후보를 출처별로 모아 보여줍니다. 추가를 눌러야 업무가 됩니다
  - `[gws 제안]` 다가오는 일정·별표 메일 (Google 연결 시)
  - `[claude 제안]` `[codex 제안]` 이 PC의 Claude·코덱스 채팅 제목

## 데이터와 개인정보

- 업무는 각 PC의 `%LOCALAPPDATA%\TODO Float\tasks.json`에만 저장되며 외부로 보내지 않습니다.
- Google 연결은 선택입니다. 회사 Google 계정으로만 로그인되며, 캘린더 일정 읽기·만들기와 Gmail의 **제목·보낸 사람**만 읽습니다. 메일 본문은 읽을 수 없는 권한입니다. 로그인 정보는 그 PC의 Windows 사용자만 풀 수 있게 암호화해 저장합니다.
- 채팅 제안은 채팅 **제목**만 봅니다.
- **이용자 수 집계**: 하루 한 번 설치 ID(무작위 값)·앱 버전·(Google을 연결했다면) 이메일의 해시값을 보냅니다. 이메일 자체와 업무 제목·메모 등 업무 내용은 보내지 않습니다. 집계는 이용자 수 하나뿐입니다.
- 이 저장소에는 실행 파일만 있으며 소스 코드는 비공개입니다.

## 요구 사항

Windows 10 또는 11 (.NET Framework 4.8 — Windows에 기본 포함)

## 달력과 공유 캘린더 (2.3.0)

- **달력 탭**에서 날짜별 마감 업무와 Google 일정을 함께 확인합니다. 날짜를 누르면 아래에 상세 목록이 표시되며 작은 창에서는 스크롤합니다. Google 연결 없이도 로컬 업무 달력은 사용할 수 있습니다.
- **캘린더 선택**에서 개인·공유받은 팀 캘린더를 체크합니다. 해당 계정에 일정 조회 권한이 있는 캘린더만 선택할 수 있습니다. 일정은 캘린더 이름·색상으로 구분하며 일부 캘린더 조회가 실패하면 안내를 표시합니다.
- 기존 연결에는 **캘린더 목록 읽기** 권한의 추가 동의가 필요할 수 있습니다. 계정이 Google OAuth 테스트 사용자로 허용돼 있어야 하는 기존 정책은 그대로 적용됩니다.
- Google 일정의 **할 일로**를 누르면 시작 날짜·시각을 마감으로 한 로컬 업무가 만들어집니다. 이후 원본 일정의 변경을 로컬 업무에 자동 반영하는 양방향 동기화는 아닙니다. **캘린더에 추가**는 기존처럼 개인 Google 캘린더에 생성합니다.
- 마감 알림은 오전 9시 이후 하루 한 번 오늘·내일 마감 및 지연 업무를 요약하고, 시각을 정한 마감은 10분 전에 알립니다. 달력의 체크박스로 켜고 끌 수 있습니다. 앱이 실행 중이어야 하며 Windows 알림·방해 금지 설정의 영향을 받습니다.
- 캘린더 이름·선택 설정은 PC에 저장하며 일정 조회 결과는 앱 메모리에서 사용합니다. 일정으로부터 직접 추가한 업무는 기존 업무 파일에 저장됩니다.
