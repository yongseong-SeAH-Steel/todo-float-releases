# TODO 플로트

윈도우 화면 오른쪽에 항상 떠 있는 작은 개인 업무 목록입니다. Google 캘린더·Gmail과 연결해 오늘 일정과 업무 후보를 함께 볼 수 있습니다.

## 받기

**[최신 버전 받기 →](https://github.com/yongseong-SeAH-Steel/todo-float-releases/releases/latest)** 에서 `TODO-Float-Portable.zip`을 받습니다.

1. zip을 계속 둘 폴더에 압축 해제합니다. (예: `문서\TODO Float`. 다운로드 폴더는 정리하다 지우기 쉬워 권하지 않습니다)
2. `TODO.exe`를 더블클릭합니다.
3. 처음 실행하면 현재 사용자 계정의 Windows 로그인 자동 실행 항목에 등록됩니다.

설치·실행 중 Windows 또는 회사 백신의 보안 안내가 나올 수 있습니다. 공식 다운로드 파일인지 확인하고 회사 보안 정책에 따라 처리하세요.

## 이미 설치한 분 — ZIP을 다시 받을 필요 없습니다

앱을 완전히 종료했다가 실행하거나 PC를 재부팅하면 새 버전을 확인합니다. 새 버전이 있으면 **변경 내용과 업데이트 여부를 묻는 창**이 뜹니다(2.2.2부터).

- **예**: 업데이트를 설치하고 앱을 다시 시작합니다. 업무·설정·Google 연결은 유지됩니다.
- **아니요**: 기존 버전으로 계속 사용하고, 다음 실행 때 다시 안내합니다.
- 이미 최신 버전이면 업데이트 안내는 뜨지 않습니다.
- 트레이 아이콘 오른쪽 클릭 → **업데이트 확인**으로 직접 확인할 수도 있습니다.

창의 **×는 트레이로 숨기기**입니다. 완전히 종료하려면 트레이 아이콘 오른쪽 클릭 → **종료**를 선택하세요.

아주 오래된 Google Drive 배포본처럼 앱 내 업데이트가 없는 버전만 최신 ZIP을 한 번 받아 실행하세요. 실행 중인 이전 앱을 닫을지 물으면 **예**를 선택합니다. 기존 업무·설정은 이어지고, 바로가기는 새 위치로 갱신됩니다.

백신의 실행 허용 안내는 TODO 업데이트 안내와 별개입니다. AhnLab V3의 ‘다음부터 묻지 않음’은 백신 실행 확인에만 적용되며 앱의 업데이트 안내를 끄지 않습니다. 회사 보안 정책에 따라 처리하세요.

## 주요 기능

- **업무 목록** — 상태(진행 전·진행 중·대기), 우선 업무, 요일 반복, 드래그로 순서 변경, 검색, 완료 이력 CSV
- **마감일과 알림** — 지연·오늘·내일 마감을 색으로 표시, 시간을 정하면 1시간·30분·10분 전 알림, 08~18시 매시간 오늘 업무 요약, 마감일순 보기
- **빠른 추가** — 어디서든 `Ctrl+Alt+T`. `견적 회신 내일 15:00`처럼 쓰면 마감까지, 앞에 `!`를 붙이면 우선 업무
- **보고서/내보내기** — 주간 보고 초안(이번 주·지난 주의 완료·진행 중·예정)을 복사하거나 완료 목록을 CSV로 저장. 좁은 창에서는 `보고서`로 표시
- **화면 설정** — LIGHT MODE / DARK MODE, 투명도 조절. 하단은 이용자 수(관리자 계정에만 표시) → 투명도 → 모드 → 보고서/내보내기 순서
- **Google 캘린더** — 진행 탭 위에 오늘 일정, 업무 수정 창에서 바로 일정 만들기
- **연동 탭** — 업무 후보를 출처별로 모아 보여줍니다. 추가를 눌러야 업무가 됩니다. 연동 설정은 탭의 **설정으로 바로가기**에서 관리합니다
  - `[gws 제안]` 다가오는 일정·별표 메일 (Google 연결 시)
  - `[claude 제안]` `[codex 제안]` 이 PC의 Claude·코덱스 채팅 제목

## 데이터와 개인정보

- 업무는 각 PC의 `%LOCALAPPDATA%\TODO Float\tasks.json`에 저장합니다. Drive 저장을 켜면 업무·메모를 연결한 Google 계정의 TODO Float 폴더에도 저장합니다. 이전 버전의 숨김 백업은 별도로 보존합니다. 집계 서버에는 업무 내용을 보내지 않습니다.
- Google 연결은 선택입니다. 회사 Google 계정으로만 로그인되며, 캘린더 일정 읽기·만들기와 Gmail의 **제목·보낸 사람**만 읽습니다. 메일 본문은 읽을 수 없는 권한입니다. 로그인 정보는 그 PC의 Windows 사용자만 풀 수 있게 암호화해 저장합니다.
- 채팅 제안은 채팅 **제목**만 봅니다.
- **이용자 수 집계**: 하루 한 번 설치 ID(무작위 값)·앱 버전·(Google을 연결했다면) 이메일의 해시값을 보냅니다. 기본 집계에는 이메일 원문과 업무 내용을 보내지 않습니다. 설정에서 관리자에게 이메일 표시를 허용하면 Google이 확인한 이메일을 집계 서버에 저장하며 개발자 관리자 계정만 목록을 조회할 수 있습니다. 허용하지 않은 사용자는 비공유 인원으로 표시합니다.
- 이 저장소에는 실행 파일만 있으며 소스 코드는 비공개입니다.

## 요구 사항

Windows 10 또는 11 (.NET Framework 4.8 — Windows에 기본 포함)

## 달력과 공유 캘린더 (2.3.1)

- **달력 탭**에서 날짜별 마감 업무와 Google 일정을 함께 확인합니다. 날짜를 누르면 아래에 상세 목록이 표시되며 작은 창에서는 스크롤합니다. Google 연결 없이도 로컬 업무 달력은 사용할 수 있습니다.
- **캘린더 선택**에서 개인·공유받은 팀 캘린더를 체크합니다. 해당 계정에 일정 조회 권한이 있는 캘린더만 선택할 수 있습니다. 일정은 캘린더 이름·색상으로 구분하며 일부 캘린더 조회가 실패하면 안내를 표시합니다.
- 기존 연결에는 **캘린더 목록 읽기** 권한의 추가 동의가 필요할 수 있습니다. 계정이 Google OAuth 테스트 사용자로 허용돼 있어야 하는 기존 정책은 그대로 적용됩니다.
- Google 일정의 **할 일로**를 누르면 시작 날짜·시각을 마감으로 한 로컬 업무가 만들어집니다. 이후 원본 일정의 변경을 로컬 업무에 자동 반영하는 양방향 동기화는 아닙니다. **캘린더에 추가**는 기존처럼 개인 Google 캘린더에 생성합니다.
- 오늘 업무 알림은 08~18시 매시간 오늘 반복 업무·오늘 마감·지연 마감 업무를 요약합니다. 미래 마감 업무는 제외합니다. 시각을 지정한 업무는 1시간·30분·10분·5분 전에 알리며 반복 업무에도 시간을 지정할 수 있습니다. 재실행 시 지난 알림을 한꺼번에 보내지 않고 현재 시간대 알림만 표시합니다. 달력의 체크박스로 켜고 끌 수 있습니다. 앱이 실행 중이어야 하며 Windows 알림·방해 금지 설정의 영향을 받습니다.
- 캘린더 이름·선택 설정은 PC에 저장하며 일정 조회 결과는 앱 메모리에서 사용합니다. 일정으로부터 직접 추가한 업무는 기존 업무 파일에 저장됩니다.

### 반복 업무 달력 (2.3.2)

반복 업무는 지정한 요일마다 달력에 표시됩니다. 완료하면 해당 날짜에 완료 상태로 한 번만 표시되고 다음 반복일에는 다시 미완료 업무로 표시됩니다. 반복 업무의 수정 창에서 날짜 없이 시간을 지정하면 각 반복일의 해당 시각을 기준으로 사전 알림을 받습니다.

### 달력 상세 표시 (2.3.4)

일반 업무는 지정 시간과 메모를 표시합니다. 반복 업무는 제목과 시간만 표시하며 메모는 수정 창에서 확인합니다. 시간이 저장되어 있지 않으면 시간 미지정으로 안내합니다. Google 일정은 제목·시간·캘린더 이름만 표시하며 일정 설명은 조회하지 않습니다. Google 연동 오류가 나면 앱에 표시되는 실제 오류 메시지를 확인해 주세요. 테스트 사용자 등록과 별개로 각 API 권한에 동의해야 하며 회사 정책의 영향을 받을 수 있습니다.

### 설정·연동과 알림 (2.4.0)

보고서 오른쪽의 톱니바퀴에서 표시할 탭과 Google·Codex·Claude Code 연동을 선택합니다. 진행 탭은 항상 표시합니다. 연동을 꺼도 등록한 업무와 메모는 남으며, Google 연결 해제와 달리 저장한 연결 정보도 유지합니다. 기존 사용자의 연동 설정은 유지됩니다.

제안 화면에도 세 연동 토글을 표시합니다. 꺼진 연동의 제안은 숨기며 새로 조회하지 않습니다. 원본 날짜가 오늘로부터 7일보다 오래된 미수락 제안은 자동으로 숨깁니다. 이미 업무로 추가한 항목과 과거 달력 기록은 삭제하지 않습니다. 이전 버전의 날짜 정보가 없는 채팅 제안은 제안 생성일을 기준으로 처리합니다.

매시간 알림은 08~18시에 오늘·지연 마감 업무 및 오늘 반복 업무만 안내합니다. 마감 날짜가 없는 일반 업무는 제외합니다. 시각을 지정한 업무는 1시간·30분·10분·5분 전에 추가 안내하며, 앱 실행 및 Windows 알림 설정이 필요합니다.

### Drive 자동 백업·복원 (2.4.0)

설정에서 **변경된 업무 자동 백업**을 켜면 Drive 앱 데이터 권한을 추가로 요청합니다. 기존 사용자에게 자동으로 추가 권한을 요청하지 않습니다. 업무·메모·반복 요일·완료 기록을 최대 1시간 간격으로 변경이 있을 때 백업하며, **지금 백업**으로 즉시 저장할 수 있습니다. 인터넷이 끊겨도 로컬 업무는 계속 사용하며 다음 기회에 다시 백업합니다.

백업은 연결한 Google 계정의 숨겨진 앱 전용 공간(appDataFolder)에 저장되므로 일반 Drive 목록에는 보이지 않습니다. **백업에서 복원**에서 날짜를 선택하세요. 복원은 현재 업무 목록을 교체하며, 직전 업무 파일을 PC에 `tasks.before-restore-날짜.json`으로 보관합니다. 로그인 토큰·개인 설정·AI 대화 기록은 백업에 포함하지 않습니다. 실시간 다중 PC 동기화 기능은 아닙니다.

백업은 덮어쓰지 않는 별도 사본으로 보관하며 현재 자동 정리하지 않습니다. Google 연동을 끄면 Drive 자동 백업도 멈춥니다. Google 계정을 바꾸면 자동 백업을 다시 켜 저장 계정을 확인해야 합니다. OAuth 테스트 상태에 따른 재인증·회사 Google 정책의 영향을 받을 수 있습니다.

### 정리된 연동 화면 (2.4.1)

제안 탭에는 Google 연동·Codex 연동·Claude Code 연동 스위치와 업무 후보만 표시합니다. 계정 이메일·연결 상태·지금 확인·캘린더 선택·연결 해제는 하단 톱니바퀴의 설정에서 확인합니다.

### 설정 구분과 관리자 이용자 목록 (2.4.2)

설정은 연동·Google Drive 백업·표시할 탭의 세 카드로 구분합니다. 연동된 드라이브 링크는 연결 계정의 Drive를 엽니다. 백업 파일은 숨겨진 앱 전용 공간에 있어 일반 Drive 목록에는 보이지 않으며 앱의 복원 버튼으로 확인합니다.

이메일 공유는 기본적으로 꺼져 있습니다. 허용하면 이메일을 이용자 집계 서버에 저장하고, 개발자 관리자만 최근 30일 이용자 목록을 확인할 수 있습니다. 관리자는 하단 사람 아이콘에 마우스를 올리거나 클릭해 목록을 봅니다. 비공유·구버전·Google 미연동 사용자는 익명 인원으로만 표시합니다. 이는 현재 접속 중인 사람 목록이 아닌 최근 30일 집계입니다.

### 일반 Drive 폴더에 업무 저장 (2.5.0)

설정의 Google Drive 저장 → **Drive에 업무 저장**을 켜고 일반 Drive 파일 권한에 동의하세요. 내 드라이브에 **TODO Float/tasks.json**을 만들고 지금까지의 업무·메모·완료·반복 기록 전체를 저장합니다. 이후 추가·수정·완료·삭제도 같은 파일에 반영합니다. **저장 폴더 열기**는 이 파일이 들어 있는 실제 폴더를 엽니다. JSON 형식의 업무 파일이며 Google Sheets 문서는 아닙니다.

로컬 업무 파일은 오프라인 캐시로 유지합니다. 변경은 약 2초 뒤 자동 반영하며 Drive의 변경도 주기적으로 확인합니다. 앱 실행·네트워크·Google 인증 상태에 따라 반영이 지연될 수 있습니다. 같은 파일을 다른 PC에서 동시에 변경하면 두 사본을 보존하고 자동 덮어쓰기를 중지합니다. Drive에서 가져오기 또는 충돌 해결을 선택하면 교체 전 사본을 PC에 남깁니다. 여러 사람이 동시에 편집하는 실시간 협업 DB는 아닙니다.

처음 연결할 때 Drive에 기존 파일이 있으면 사용할 업무를 선택합니다. PC가 비어 있으면 Drive 업무를 가져오고, 양쪽에 업무가 있으면 선택 없이 덮어쓰지 않습니다. 저장 기능을 끄거나 Google 계정을 바꾸면 기존 Drive 파일은 보존됩니다. 기존 숨김 백업은 삭제하지 않으며 이전 숨김 백업 불러오기에서 이용할 수 있습니다. 새 저장 방식이 연결되면 예전 자동 숨김 백업은 중지합니다.
